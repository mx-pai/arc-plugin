## Cmd+T 探针与手动边界

隔离测试扩展申请 `Command+T`，Chrome `commands.getAll()` 返回该命令的 shortcut 为空，正式命令面板使用 `Command+Shift+K`，正式注册结果另存为 registeredCommands

探针验证的是注册结果，桌面物理按键的分发、Cmd+T 地址栏焦点和用户现有快捷键冲突仍需在 Chrome 中验收

网页命令面板的自动化注入使用测试扩展临时增加的 `http://127.0.0.1/*` 权限，正式 manifest 使用 activeTab，真实用户手势到临时授权的链路保留为桌面手动验收项

分屏通过能力探测调用 `chrome.tabs.createSplit`，隔离环境已验证双页 `splitViewId` 一致与 `unsplit` 解除；三页与四页组合按子项顺序逐项打开，单页组合返回明确错误且不残留标签，Chrome 155 桌面端的分屏邻接与布局操作仍需手动确认

## 本地真实数据的只读检查

当前 Arc 侧栏快照识别到工作、OKR、个人三个命名空间，并将两个窗口本地临时容器单独呈现，共 727 条可打开链接、66 个文件夹、10 组分屏、1 条不支持网址提示

解析结果经过备份结构校验，项目与测试配置保存聚合统计，真实侧栏文件及网址清单未写入仓库，日常 Chrome 的数据导入由设置页的确认操作触发

## 已知限制

- 原生 Cmd+T 与地址栏焦点无法被扩展接管，交付为定制新标签页、可选聚焦面板、⇧⌘K 与 `arc` 关键字
- 命令面板注入使用隔离测试扩展的 localhost 授权，正式 activeTab 授权链需原生快捷键验收
- 原生书签顺序调整（`onChildrenReordered`）不同步，只同步增删改移
- Peek 失焦自动关闭、Little Arc 窗口位置与焦点受桌面窗口管理器影响
- 自动归档 alarm 的真实触发周期受 Chrome 后台节流影响，隔离测试只验证注册与设置
